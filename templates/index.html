\ SELF_HOSTED_INFRASTRUCTURE

The conceptual topology showing how my development code moves from local machines to containerized server deployments.

1. Clean Deploy Loops

Rather than deploying via manual CLI tools, I explore automated workflows. Pushing to GitHub triggers Webhook notifications to my Debian Server.

2. Docker Containerization

Each ML model or app wrapper has its own environment definitions. By binding volume maps, I make sure databases persist separate from execution scripts.

3. Coolify Server Deployments

By managing configurations through Coolify, I receive SSL certificates automatically, manage port proxies, and see resource usage metrics in real-time.
